# 素材：欧洲40°热浪，老外冲进商场疯抢美的空调

来源：新浪科技热点小时报 2026年07月08日 + 刘润《美的空调，专治欧洲各种不服》

## 核心事实

- 2026年6月底开始，欧洲一系列国家遭遇40°C以上极端高温，纪录不断被打破，甚至热死了人（字面意义上）。
- 欧洲国家整体位于中高纬度：巴黎纬度比哈尔滨还靠北，柏林和漠河差不多。很少极端高温，空调普及率只有约 20%。
- 于是许多商场出现类似场景：热疯的人们守在商场门口，一开门就冲进家电区，连抓带挠地抢购空调。
- 参与抢购的品牌：日本大金、韩国 LG/三星、中国美的/格力/海尔。
- 中国空调（美的为首）凭借性价比、产能、快速交付，成为这波欧洲抢购潮的主力，"专治欧洲各种不服"。

## 可漫画化的张力点

1. 欧洲人一直以"我们不需要空调"自豪（气候温和、环保叙事），结果极端高温打脸。
2. 纬度认知反差：巴黎比哈尔滨还北，却热到扛不住。
3. 商场开门瞬间，人群"冲锋"抢空调的喜剧画面。
4. 各国品牌同台，中国空调凭实力出圈。
